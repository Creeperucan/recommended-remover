# About

# Installation
1. Download the ZIP and extract it.
2. Open Chrome and navigate to:
   
```
   chrome://extensions
```
3. Enable Developer mode using the toggle in the top-right corner.
4. Click "Load unpacked" and select the `recommended-remover` folder.
5. Done!
